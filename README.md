## 요구 사항

### 상품

- 각 상품은 고유 id가 있다
- 상품은 가격이 있다
  - 가격은 0 이상이어야 한다
- 상품 가격은 변경할 수 있다
  - 해당 상품을 포함하는 메뉴들도 영향을 받는다
    - 메뉴에 있는 해당 상품은 변경된 상품 가격으로 바뀐다
    - 메뉴의 가격이 속한 상품 가격들의 합을 넘으면 숨김 상태가 된다
- 상품 리스트를 볼 수 있다

### 메뉴 그룹

- 각 메뉴 그룹은 고유 id가 있다
- 메뉴 그룹은 이름이 있다
  - 이름은 비어있을 수 없다
- 메뉴 그룹 리스트를 볼 수 있다

### 메뉴

- 각 메뉴는 고유 id가 있다
- 메뉴에는 이름이 있다
  - 욕설이 들어갈 수 없다
    - 욕설 여부는 외부 서비스를 활용한다
- 메뉴에는 가격이 있다
  - 가격은 0 이상이어야한다
  - 메뉴에 속한 내역들의 합을 넘을 수 없다
- 메뉴는 하나의 메뉴 그룹에 속해야 한다
- 메뉴는 숨김 여부를 선택할 수 있다
  - 최초 생성 시 선택할 수 있다
  - 숨김 여부는 변경 가능하다
- 메뉴에는 여러 상품이 속할 수 있다
  - 상품 종류는 최소 한 개 이상이어야한다
  - 상품 수량은 최소 한 개 이상이어야한다
- 메뉴 리스트를 조회할 수 있다

### 주문 공통

- 각 주문은 고유 id가 있다
- 주문은 하나의 주문 타입을 선택해야한다
  - 배달, 포장, 매장 식사 3가지 타입이 있다
- 주문은 주문 항목이 있어야한다
  - 주문 항목은 최소 한 개가 있어야 한다
  - 주문 항목은 여러 개일 수 있다
- 숨겨진 메뉴 메뉴를 주문할 수 없다
- 주문은 주문 상태를 가진다
  - 최초 등록 시 대기(WAITING) 상태이다
  - 완료(COMPLETED) 상태가 되면 주문이 최종적으로 끝난 것이다
- 주문 접수 시 주문 상태는 접수(ACCEPTED) 상태가 된다
  - 이전 주문 상태가 대기(WAITING) 상태여야 한다
- 주문 리스트를 볼 수 있다

### 주문>포장
- 포장 주문의 상태는 대기(WAITING), 접수(ACCEPTED), 조리 완료(SERVED), 주문 완료(COMPLETED) 4가지 상태가 있다
  - 주문 완료가 되려면 조리 완료 상태여야한다

### 주문>배달
- 배달 주문의 상태는 대기(WAITING), 접수(ACCEPTED), 조리 완료(SERVED), 배달 중(DELIVERING), 주문 완료(COMPLETED) 6가지 상태가 있다
- 주문 접수 시 배달을 요청한다
  - 배달을 요청할 때는 주문 id, 가격, 배달 주소가 필요하다
- 주문 타입이 배달이어야만 배달을 시작할 수 있다
  - 배달 시작 시 주문 상태는 배달 중으로 변경된다
- 주문 상태가 조리 완료이면 배달을 시작할 수 없다
- 배달 완료는 이전 상태가 배달 중이어야 가능하다
- 주문 완료는 이전 상태가 배달 완료여야 가능하다

### 주문>매장 식사
- 매장 식사 주문의 상태는 대기(WAITING), 접수(ACCEPTED), 조리 완료(SERVED), 주문 완료(COMPLETED) 4가지 상태가 있다
- 매장 내에 주문 가능한 테이블을 주문 테이블이라고 부른다
- 주문 테이블은 고유 id가 있어야 한다
- 주문 테이블은 이름이 있어야한다
- 주문 테이블은 현재 이용자 수를 알고 있어야한다
  - 최초 생성 시에는 0명이다
- 주문 테이블은 이용 상태를 가진다
  - 최초 등록 시 이용 가능 상태이다
- 주문 테이블을 이용 시 이용 중 상태로 바뀐다
- 주문 완료가 되려면 조리 완료 상태여야한다
- 매장 식사가 완료되면 해당 주문 테이블을 비운다
  - 주문 테이블을 이용 가능 상태로 변경한다
  - 주문 테이블 이용자 수를 0명으로 바꾼다

## 용어 사전

### 전체 공통
| 한글명    | 영문명              | 설명                                               |
|--------|------------------|--------------------------------------------------|
| 외부 서비스 | external service | 우리가 만든 시스템 밖에서 제공하는 기능 (ex. 지도를 위한 네이버, 구글 등 사용) |
| 욕설     | profanity        | 사회적으로 불쾌하거나 부적절한 언어로 간주되는 직/간접적인 단어 또는 표현        |

### 상품
| 한글명   | 영문명           | 설명             |
|-------|---------------|----------------|
| 상품    | product       | 판매할 수 있는 물품    |
| 상품 id | product id    | 상품을 식별하는 고유한 값 |
| 상품 가격 | product price | 상품을 판매하는 가격    |

### 메뉴 그룹
| 한글명      | 영문명           | 설명                                  |
|----------|---------------|-------------------------------------|
| 메뉴 그룹 id | menu group id | 메뉴 그룹을 식별하는 고유한 값                   |
| 메뉴 그룹    | menu group    | 여러 개의 메뉴로 구성된 그룹 (ex.1인 메뉴, 오늘의 메뉴) |

### 메뉴
| 한글명    | 영문명                | 설명                             |
|--------|--------------------|--------------------------------|
| 메뉴 id  | menu id            | 메뉴를 식별하는 고유한 값                 |
| 메뉴     | menu               | 1개 이상의 상품으로 구성되어, 주문 가능한 최소 단위 |
| 메뉴 가격  | menu price         | 메뉴를 판매하는 가격                    |
| 숨겨진 메뉴 | not displayed menu | 메뉴는 존재하나 주문할 수 없는 메뉴           |
| 내역     | menu product       | 메뉴에 속한 상품과 수량                  |

### 주문 공통
| 한글명   | 영문명        | 설명                             |
|-------|------------|--------------------------------|
| 주문 id | order id   | 주문을 식별하는 고유한 값                 |
| 배달    | delivering | 가게의 음식을 고객이 지정한 위치까지 가져다 주는 것  |
| 매장 식사 | eat in     | 고객이 매장 내에서 식사하는 것              |
| 포장    | take out   | 고객이 주문한 가게에 직접 방문하여 음식을 가져가는 것 |
| 주문 타입 | order type | 주문의 종류를 나타내는 것 (배달, 매장 식사, 포장) |
| 주문 항목 | order line | 주문에 포함된 메뉴와 수량을 나타내는 것         |
| 대기    | waiting    | 고객이 주문을 하였으나 아직 가게에서 접수하기 전 상태 |
| 접수    | accepted   | 가게에서 주문을 접수하여 조리가 시작된 상태       |
| 조리 완료 | served     | 조리가 완료되어 고객에게 전달 가능한 상태        |
| 주문 완료 | completed  | 주문의 모든 과정이 종료된 상태              |

### 배달 주문
| 한글명    | 영문명              | 설명                     |
|--------|------------------|------------------------|
| 배달 대행사 | delivery agency  | `배달`을 실행하는 배달원이 소속된 업체 |
| 배달 주소  | delivery address | `배달`을 받을 주소            |
| 배달 중   | delivering       | `배달`이 진행 중인 상태         |
| 배달 완료  | delivered        | `배달`이 완료된 상태           |

### 매장 식사
| 한글명       | 영문명              | 설명                 |
|-----------|------------------|--------------------|
| 주문 테이블    | order table      | 주문이 가능한 테이블        |
| 주문 테이블 id | order table id   | 주문 테이블을 식별하는 고유한 값 |
| 이용자       | order table user | 주문 테이블에서 식사를 하는 사람 | 
| 이용 가능     | available        | 주문 테이블이 사용 가능한 상태  |
| 이용 중      | in use           | 주문 테이블이 사용 중인 상태   |
